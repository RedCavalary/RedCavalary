# Red Cavalary GitHub Profile Setup

1. Back up any current files in your `RedCavalary` profile repository.
2. Upload `README.md` and the full `assets/` directory, preserving file paths.
3. Commit to the default branch.
4. GitHub renders `README.md` on your profile when the repository is public and named exactly `RedCavalary`.

The README uses relative asset paths such as `assets/01-master-battlefield-banner.png`. Do not upload only the README; upload the assets folder too.

## Asset note
The included image set is separated from a generated concept-sheet composite. Some small art panels are crops/upscaled from that sheet, not individually rendered at their labeled mockup dimensions. The horse sprite sheet and animated GIF are concept visuals rather than game-ready transparent sprites.
